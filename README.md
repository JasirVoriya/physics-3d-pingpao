# 平抛运动实验 · 3D 互动课件

高一物理「抛体运动」学生实验的交互式 3D 课件，适合学生自学和老师课堂演示。

- **在线体验**：https://jasirvoriya.github.io/physics-3d-pingpao/
- **仓库**：https://github.com/JasirVoriya/physics-3d-pingpao
- **离线使用**：下载 `index.html`，双击用 Chrome / Edge 打开即可，不需要联网，不需要安装。手机浏览器也能看。

## 内容（8 步）
1. **认识器材**：点击场景里的木板坐标纸、斜槽、释放挡块、钢球、挡板、重锤线、刻度尺、原点，看名称和作用。
2. **谁先落地**：平抛球与自由落体球同时释放，频闪影子逐时刻对比，看到同时落地。
3. **调平槽口**：槽口初始是歪的，调倾角并「放球检验」，不水平不能进入下一步。
4. **描点**：拖动挡板到不同高度释放小球，自动记点（≥5 个），一键连成平滑曲线，可对照理论曲线 y = gx²/(2v₀²)。
5. **频闪验证**：频闪间隔可调，表格显示 Δx 相等、相邻 Δy 之差恒为 gT²。
6. **算初速度**：原点法、等间距三点法各一题，填数判对错并给出完整计算过程。
7. **误差探究**：槽口上翘、下倾、释放高度不一致、原点取在槽口边缘，四种情况自动做实验，判断 v₀ 偏大/偏小/时大时小，附解析。
8. **小测验**：8 道题（选择 + 填数），交卷给分和逐题解析。

可调参数：释放高度 5–30 cm、槽口倾角 −10°~+10°、挡板高度 5–60 cm、频闪间隔 0.02–0.1 s、慢放 0.1×–1×，g 固定 9.8 m/s²。初速度按 v₀ = √(2gh) 估算（理想化：忽略摩擦和滚动）。

## 自测结果（2026-11-13，Chrome 无头浏览器）
- 离线打开，无任何网络请求，控制台无报错/警告。
- 描点与理论曲线最大偏差 0.24%（要求 < 1%）；三点法算出 v₀ 与设定值偏差 0.00%（要求 < 2%）。
- 两球落地时间相同（0.378 s）；频闪 Δx 恒定、Δ(Δy) 恒为 2.45 cm = gT²。
- 第 3 步倾角 ≠ 0 时「下一步」禁用；四种误差情形结论与程序计算一致；测验全对得 100 分。

```
cd src && npm pack three@0.147.0 && tar xzf three-0.147.0.tgz && cd .. && python3 build.py
```
